# Bütçe Göstergesi (MyWishlist)

Liste toplamının bütçeye oranı ve kalan tutar.

**Kimlik:** `PLC-073` · **Kategori:** Ürün Kalıpları · **Katman:** temel

**Ne zaman:** MyWishlist bütçe planı, alışveriş listeleri.

**Sınıflar:** `pl-kpi + pl-progress`

**Kapsayıcı:** `<div data-pl data-pl-theme="dark" data-pl-product="wishlist" lang="tr">`

**Erişilebilirlik:** Tutarlar ₺ ile metin olarak; aşımda uyarı rengi + metin.

**Tüketiciden beklenen:** `components/bundle.css` yüklü olmalı; örnekteki HTML yapısı ve sınıf adları aynen korunur. İkonlar Lucide (1.75 px), satır içi SVG.
