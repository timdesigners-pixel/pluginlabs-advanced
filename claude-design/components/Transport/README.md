# Oynatma Kontrolleri

Zaman kodu (geçen / toplam), başa sar, kare geri, oynat, kare ileri, sona.

**Kimlik:** `PLA-064` · **Kategori:** Yaratıcı Araçlar · **Katman:** advanced

**Ne zaman:** Kurgu, kayıt oynatma, sunum provası.

**Sınıflar:** `pl-transport pl-transport__tc .is-main`

**Kapsayıcı:** `<div data-pl data-pl-theme="dark" lang="tr">`

**Erişilebilirlik:** Boşluk tuşu oynat/duraklat; J-K-L kısayolları önerilir.

**Desen kaynağı:** Pinler 17, 21 — zaman kodu ve oynatma düğmeleri

**Tüketiciden beklenen:** `components/bundle.css` yüklü olmalı; örnekteki HTML yapısı ve sınıf adları aynen korunur. İkonlar Lucide (1.75 px), satır içi SVG.
