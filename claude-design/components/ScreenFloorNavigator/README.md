# Kat Planı Navigatörü

Gradyan zemin üzerinde cam yüzeyli pencere: ikon rayı, izometrik kat ve sıcak noktalar, saat/hava widget'ı, rota düğmesi ve sağda kat seçici paneli.

**Kimlik:** `PLA-102` · **Kategori:** Ekran Şablonları · **Katman:** advanced

**Ne zaman:** Ofis/tesis rota bulma, oda rezervasyonu, ziyaretçi kiosku.

**Sınıflar:** `pl-screen--backdrop + pl-window + pl-rail + pl-isoplan + pl-hotspot + pl-weather + pl-floorpanel`

**Kapsayıcı:** `<div data-pl data-pl-theme="dark" data-pl-surface="glass" lang="tr">`

**Erişilebilirlik:** Harita alternatifi: oda listesi + 'Rota oluştur' düğmesi.

**Desen kaynağı:** Pin 15 — cam panelli ofis kat planı ve rota bulma

**Tüketiciden beklenen:** `components/bundle.css` yüklü olmalı; örnekteki HTML yapısı ve sınıf adları aynen korunur. İkonlar Lucide (1.75 px), satır içi SVG.
