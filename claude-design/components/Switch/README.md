# Anahtar (Toggle)

Anında etki eden açık/kapalı ayarı.

**Kimlik:** `PLC-022` · **Kategori:** Form · **Katman:** temel

**Ne zaman:** Değişiklik 'Kaydet' gerektirmiyorsa. Gerektiriyorsa onay kutusu kullan.

**Sınıflar:** `pl-switch > input[type=checkbox][role=switch]`

**Kapsayıcı:** `<div data-pl data-pl-theme="dark" lang="tr">`

**Erişilebilirlik:** role="switch" + aria-checked.

**Tüketiciden beklenen:** `components/bundle.css` yüklü olmalı; örnekteki HTML yapısı ve sınıf adları aynen korunur. İkonlar Lucide (1.75 px), satır içi SVG.
