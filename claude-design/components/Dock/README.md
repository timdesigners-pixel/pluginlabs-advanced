# Dock / Başlatıcı (Flow Dock)

Yüzen uygulama/kısayol rafı; çalışan uygulama göstergeli.

**Kimlik:** `PLC-062` · **Kategori:** Ürün Kalıpları · **Katman:** temel

**Ne zaman:** Flow Dock ana yüzeyi, hızlı başlatıcılar.

**Sınıflar:** `pl-dock pl-dock__item.is-running pl-dock__sep`

**Kapsayıcı:** `<div data-pl data-pl-theme="dark" data-pl-product="flowdock" lang="tr">`

**Erişilebilirlik:** role="toolbar"; ← → gezinme; her öğede aria-label + tooltip.

**Tüketiciden beklenen:** `components/bundle.css` yüklü olmalı; örnekteki HTML yapısı ve sınıf adları aynen korunur. İkonlar Lucide (1.75 px), satır içi SVG.
