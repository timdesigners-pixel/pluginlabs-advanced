# İkon Rayı

72px genişlikte, logo karosu + ikon öğeleri + alt yardımcılar. Aktif öğe aksan zemini ve sol çizgiyle işaretlenir; hover'da etiket ipucu açılır.

**Kimlik:** `PLA-002` · **Kategori:** Kabuk & Pencere · **Katman:** advanced

**Ne zaman:** İçerik alanının maksimum olması gereken yoğun uygulamalar (kurgu, harita, komuta ekranı).

**Durumlar:** varsayılan, hover (ipucu), aktif, rozetli

**Sınıflar:** `pl-rail pl-rail__logo pl-rail__item is-active pl-rail__tip pl-rail__spacer`

**Kapsayıcı:** `<div data-pl data-pl-theme="dark" lang="tr">`

**Erişilebilirlik:** <nav aria-label>; her öğe aria-label + görünür ipucu; aktif öğe aria-current="page".

**Desen kaynağı:** Pinler 5, 7, 14, 15, 18, 21, 26 — 72px dikey ikon gezinmesi

**Tüketiciden beklenen:** `components/bundle.css` yüklü olmalı; örnekteki HTML yapısı ve sınıf adları aynen korunur. İkonlar Lucide (1.75 px), satır içi SVG.
