# Tarif Kartı (Mutfak Atölyesi)

Görsel + başlık + süre/porsiyon/zorluk meta satırı.

**Kimlik:** `PLC-064` · **Kategori:** Ürün Kalıpları · **Katman:** temel

**Ne zaman:** Mutfak Atölyesi kayıtlı tarifler, web'den yakalanan tarifler.

**Sınıflar:** `pl-recipe pl-recipe__img pl-recipe__meta`

**Kapsayıcı:** `<div data-pl data-pl-theme="dark" data-pl-product="mutfak" lang="tr">`

**Erişilebilirlik:** Görsel alt metni yemeğin adı; meta ikonları aria-hidden, metin okunur.

**Tüketiciden beklenen:** `components/bundle.css` yüklü olmalı; örnekteki HTML yapısı ve sınıf adları aynen korunur. İkonlar Lucide (1.75 px), satır içi SVG.
