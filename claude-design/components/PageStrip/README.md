# Sayfa Film Şeridi

Numaralı sayfa küçük resimleri ve ekleme düğmesi; etkin sayfa aksan çerçeveli.

**Kimlik:** `PLA-069` · **Kategori:** Yaratıcı Araçlar · **Katman:** advanced

**Ne zaman:** Çok sayfalı tasarım, sunum, karusel gönderi düzenleme.

**Sınıflar:** `pl-pagestrip pl-pagestrip__p is-active pl-pagestrip__add`

**Kapsayıcı:** `<div data-pl data-pl-theme="dark" lang="tr">`

**Erişilebilirlik:** role="tablist"; sürükle-bırak için klavye alternatifi (Alt+←/→).

**Desen kaynağı:** Pin 22 — alttaki sayfa küçük resimleri

**Tüketiciden beklenen:** `components/bundle.css` yüklü olmalı; örnekteki HTML yapısı ve sınıf adları aynen korunur. İkonlar Lucide (1.75 px), satır içi SVG.
