# İpucu (Tooltip)

Kısa açıklama veya kısayol bilgisi.

**Kimlik:** `PLC-015` · **Kategori:** Temel · **Katman:** temel

**Ne zaman:** İkon butonlarda, kısaltılmış metinlerde. Asla kritik bilgi taşımaz.

**Sınıflar:** `pl-tooltip`

**Kapsayıcı:** `<div data-pl data-pl-theme="dark" lang="tr">`

**Erişilebilirlik:** role="tooltip" + tetikleyicide aria-describedby; odakla da açılır, Esc kapatır.

**Tüketiciden beklenen:** `components/bundle.css` yüklü olmalı; örnekteki HTML yapısı ve sınıf adları aynen korunur. İkonlar Lucide (1.75 px), satır içi SVG.
