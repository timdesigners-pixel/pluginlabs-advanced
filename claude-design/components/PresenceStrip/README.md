# Üye Varlık Şeridi

Avatar + ad + konum durumu hapları; evdeki üyeler aksan halkalı.

**Kimlik:** `PLA-029` · **Kategori:** Akıllı Ev & IoT · **Katman:** advanced

**Ne zaman:** Aile/ekip varlık durumu, paylaşımlı çalışma alanı katılımcıları.

**Durumlar:** evde, dışarıda, çevrimdışı

**Sınıflar:** `pl-presence pl-presence__item is-home`

**Kapsayıcı:** `<div data-pl data-pl-theme="dark" lang="tr">`

**Erişilebilirlik:** Durum metni görünür; yalnız halka rengine güvenilmez.

**Desen kaynağı:** Pin 6 — alt kısımda ev üyeleri avatarları

**Tüketiciden beklenen:** `components/bundle.css` yüklü olmalı; örnekteki HTML yapısı ve sınıf adları aynen korunur. İkonlar Lucide (1.75 px), satır içi SVG.
