# Hub Kenar Çubuğu

PluginLabs Hub'ın ana gezinmesi: marka, bölümler, uygulamalar.

**Kimlik:** `PLC-028` · **Kategori:** Gezinme · **Katman:** temel

**Ne zaman:** Masaüstü Hub ve tam ekran web panellerinde birincil gezinme.

**Sınıflar:** `pl-sidebar pl-sidebar__brand pl-sidebar__section pl-navitem.is-active`

**Kapsayıcı:** `<div data-pl data-pl-theme="dark" data-pl-product="hub" lang="tr">`

**Erişilebilirlik:** <nav aria-label="Ana menü">; aktif öğede aria-current="page".

**Tüketiciden beklenen:** `components/bundle.css` yüklü olmalı; örnekteki HTML yapısı ve sınıf adları aynen korunur. İkonlar Lucide (1.75 px), satır içi SVG.
