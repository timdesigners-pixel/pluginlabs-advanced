# Pencere Başlık Çubuğu

Çerçevesiz masaüstü penceresi için başlık, global arama ve pencere kontrolleri.

**Kimlik:** `PLC-029` · **Kategori:** Gezinme · **Katman:** temel

**Ne zaman:** Electron/Tauri çerçevesiz pencerelerde (Hub, Flow Dock ayarları, Tweakster).

**Sınıflar:** `pl-titlebar pl-titlebar__center pl-titlebar__search pl-winctl`

**Kapsayıcı:** `<div data-pl data-pl-theme="dark" data-pl-product="hub" lang="tr">`

**Erişilebilirlik:** Sürüklenebilir alan -webkit-app-region: drag; butonlar no-drag ve aria-label'lı.

**Tüketiciden beklenen:** `components/bundle.css` yüklü olmalı; örnekteki HTML yapısı ve sınıf adları aynen korunur. İkonlar Lucide (1.75 px), satır içi SVG.
