# Renk Seçici

Önceden tanımlı renk paleti seçimi.

**Kimlik:** `PLC-026` · **Kategori:** Form · **Katman:** temel

**Ne zaman:** Not/etiket rengi, tema aksanı, Design Replicator palet çıkarımı.

**Sınıflar:** `pl-swatches > .pl-swatch.is-selected`

**Kapsayıcı:** `<div data-pl data-pl-theme="dark" lang="tr">`

**Erişilebilirlik:** role="radiogroup"; her renk aria-label ile adlandırılır.

**Tüketiciden beklenen:** `components/bundle.css` yüklü olmalı; örnekteki HTML yapısı ve sınıf adları aynen korunur. İkonlar Lucide (1.75 px), satır içi SVG.
