# Kod Çıkarım Kartı (Leo Helper)

Telegram mesajından çıkarılan kod, koşullar ve kaynak.

**Kimlik:** `PLC-065` · **Kategori:** Ürün Kalıpları · **Katman:** temel

**Ne zaman:** Leo Helper akışı, popup detay, bildirim genişletme.

**Durumlar:** geçerli, süresi doldu, düzeltildi (geri bildirim)

**Sınıflar:** `pl-extract pl-extract__code + pl-kv`

**Kapsayıcı:** `<div data-pl data-pl-theme="dark" data-pl-product="leo" lang="tr">`

**Erişilebilirlik:** Kod metni seçilebilir; kopyala butonu sonrası 'Kopyalandı' duyurusu.

**Tüketiciden beklenen:** `components/bundle.css` yüklü olmalı; örnekteki HTML yapısı ve sınıf adları aynen korunur. İkonlar Lucide (1.75 px), satır içi SVG.
