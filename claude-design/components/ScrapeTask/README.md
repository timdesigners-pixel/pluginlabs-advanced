# Kazıma Görevi Kartı (Scrapper)

Çok sayfalı kazıma/veri toplama görevinin durumu ve çıktısı.

**Kimlik:** `PLC-071` · **Kategori:** Ürün Kalıpları · **Katman:** temel

**Ne zaman:** The Ultimate Scrapper görev listesi.

**Durumlar:** kuyrukta, çalışıyor, tamamlandı, hata

**Sınıflar:** `pl-card + pl-progress + pl-kv`

**Kapsayıcı:** `<div data-pl data-pl-theme="dark" data-pl-product="scrapper" lang="tr">`

**Erişilebilirlik:** Görev durumu metinle; ilerleme aria-valuenow.

**Tüketiciden beklenen:** `components/bundle.css` yüklü olmalı; örnekteki HTML yapısı ve sınıf adları aynen korunur. İkonlar Lucide (1.75 px), satır içi SVG.
