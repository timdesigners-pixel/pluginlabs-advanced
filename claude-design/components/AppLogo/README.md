# Uygulama Logo Karosu

Ürün aksanından türeyen gradyan logo karosu.

**Kimlik:** `PLC-053` · **Kategori:** Ürün Kalıpları · **Katman:** temel

**Ne zaman:** Katalog, kenar çubuğu, dock, bildirim, popup başlığı.

**Sınıflar:** `pl-applogo pl-applogo--sm|lg [data-pl-product]`

**Kapsayıcı:** `<div data-pl data-pl-theme="dark" lang="tr">`

**Erişilebilirlik:** Dekoratifse aria-hidden; tek başına kullanılıyorsa aria-label=ürün adı.

**Tüketiciden beklenen:** `components/bundle.css` yüklü olmalı; örnekteki HTML yapısı ve sınıf adları aynen korunur. İkonlar Lucide (1.75 px), satır içi SVG.
