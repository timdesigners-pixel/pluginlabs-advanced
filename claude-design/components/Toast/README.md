# Toast Bildirimi

Geçici, köşede beliren işlem sonucu; geri alma sunar.

**Kimlik:** `PLC-048` · **Kategori:** Geri Bildirim · **Katman:** temel

**Ne zaman:** Eylem sonuçları: kaydedildi, kopyalandı, arşivlendi (Geri al).

**Sınıflar:** `pl-toast pl-toast__body pl-toast__action`

**Kapsayıcı:** `<div data-pl data-pl-theme="dark" lang="tr">`

**Erişilebilirlik:** Kapsayıcı role="status" aria-live="polite"; hata ise role="alert". En az 5 sn.

**Tüketiciden beklenen:** `components/bundle.css` yüklü olmalı; örnekteki HTML yapısı ve sınıf adları aynen korunur. İkonlar Lucide (1.75 px), satır içi SVG.
