# Avatar

Kullanıcı ya da kanal kimliği; baş harf veya görsel.

**Kimlik:** `PLC-009` · **Kategori:** Temel · **Katman:** temel

**Ne zaman:** Hesap menüsü, Telegram kanal listesi, yorumlar.

**Durumlar:** sm, md, lg, accent, çevrimiçi

**Sınıflar:** `pl-avatar pl-avatar--sm|lg pl-avatar--accent is-online`

**Kapsayıcı:** `<div data-pl data-pl-theme="dark" lang="tr">`

**Erişilebilirlik:** Görselde alt, baş harfte aria-label ile tam ad.

**Tüketiciden beklenen:** `components/bundle.css` yüklü olmalı; örnekteki HTML yapısı ve sınıf adları aynen korunur. İkonlar Lucide (1.75 px), satır içi SVG.
