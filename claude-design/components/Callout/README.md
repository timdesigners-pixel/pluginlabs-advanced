# Uyarı Kutusu (Callout)

Sayfa içi kalıcı bilgi/uyarı; sol renkli kenarlık.

**Kimlik:** `PLC-047` · **Kategori:** Geri Bildirim · **Katman:** temel

**Ne zaman:** Önemli bağlam, risk, ipucu. Geçici bildirim için Toast.

**Durumlar:** info, success, warning, danger, accent

**Sınıflar:** `pl-callout pl-callout--success|warning|danger|accent pl-callout__title`

**Kapsayıcı:** `<div data-pl data-pl-theme="dark" lang="tr">`

**Erişilebilirlik:** Kritikse role="alert", değilse role="note".

**Tüketiciden beklenen:** `components/bundle.css` yüklü olmalı; örnekteki HTML yapısı ve sınıf adları aynen korunur. İkonlar Lucide (1.75 px), satır içi SVG.
