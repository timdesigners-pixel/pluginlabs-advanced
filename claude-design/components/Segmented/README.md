**Kimlik:** `PLC-003` · **Kategori:** Temel · **Katman:** temel

**Ne zaman:** Görünüm modu (ızgara/liste), zaman aralığı, kapsam seçimi.

**Durumlar:** seçili, hover

**Sınıflar:** `pl-segment > button.is-active`

**Kapsayıcı:** `<div data-pl data-pl-theme="dark" lang="tr">`

**Erişilebilirlik:** role="tablist" + role="tab" + aria-selected; ok tuşlarıyla gezinme.

**Tüketiciden beklenen:** `components/bundle.css` yüklü olmalı; örnekteki HTML yapısı ve sınıf adları aynen korunur. İkonlar Lucide (1.75 px), satır içi SVG.
