# Avatar Grubu

Üst üste binen avatarlar + fazlalık sayacı.

**Kimlik:** `PLC-010` · **Kategori:** Temel · **Katman:** temel

**Ne zaman:** Paylaşılan pano, takip edilen kanallar, ortak çalışanlar.

**Sınıflar:** `pl-avatars > .pl-avatar`

**Kapsayıcı:** `<div data-pl data-pl-theme="dark" lang="tr">`

**Erişilebilirlik:** Grup için aria-label="5 kişi".

**Tüketiciden beklenen:** `components/bundle.css` yüklü olmalı; örnekteki HTML yapısı ve sınıf adları aynen korunur. İkonlar Lucide (1.75 px), satır içi SVG.
