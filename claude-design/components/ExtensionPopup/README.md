# Eklenti Popup İskeleti

380×560 tarayıcı eklentisi popup'ı: başlık, durum, içerik, alt eylem çubuğu.

**Kimlik:** `PLC-056` · **Kategori:** Ürün Kalıpları · **Katman:** temel

**Ne zaman:** Tüm PluginLabs tarayıcı eklentilerinin popup'ı bu iskeletle başlar.

**Sınıflar:** `pl-popup pl-popup__head pl-popup__title pl-popup__body pl-popup__foot [data-pl-density=compact]`

**Kapsayıcı:** `<div data-pl data-pl-theme="dark" data-pl-product="leo" lang="tr">`

**Erişilebilirlik:** Popup açıldığında ilk odak birincil eylemde; Tab sırası yukarıdan aşağı.

**Tüketiciden beklenen:** `components/bundle.css` yüklü olmalı; örnekteki HTML yapısı ve sınıf adları aynen korunur. İkonlar Lucide (1.75 px), satır içi SVG.
