# Saat & Hava Widget'ı

Gün + büyük saat ve tarih; yanında gradyan zeminli sıcaklık karosu.

**Kimlik:** `PLA-032` · **Kategori:** Akıllı Ev & IoT · **Katman:** advanced

**Ne zaman:** Pano üst köşesi, kilit/boşta ekranı, ortam bilgisi.

**Sınıflar:** `pl-weather pl-glass pl-weather__time pl-weather__day pl-weather__clock pl-weather__temp`

**Kapsayıcı:** `<div data-pl data-pl-theme="dark" data-pl-surface="glass" lang="tr">`

**Erişilebilirlik:** <time datetime> kullanılır.

**Desen kaynağı:** Pin 15 — 'Tue 08:25 pm' + gradyan sıcaklık kartı

**Tüketiciden beklenen:** `components/bundle.css` yüklü olmalı; örnekteki HTML yapısı ve sınıf adları aynen korunur. İkonlar Lucide (1.75 px), satır içi SVG.
