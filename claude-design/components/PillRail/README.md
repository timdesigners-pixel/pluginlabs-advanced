# Yüzen Hap Ray

Aksan renginde dolu, köşeleri 28px hap ray. Aktif öğe yüzey renginde 'kesik' karo olarak öne çıkar.

**Kimlik:** `PLA-003` · **Kategori:** Kabuk & Pencere · **Katman:** advanced

**Ne zaman:** Açık temalı, samimi tüketici panelleri (fitness, sağlık, kişisel finans).

**Durumlar:** varsayılan, hover, aktif

**Sınıflar:** `pl-pillrail pl-pillrail__item is-active`

**Kapsayıcı:** `<div data-pl data-pl-theme="dark" lang="tr">`

**Erişilebilirlik:** Aksan zemininde ikon kontrastı ≥3:1 olmalı; --pl-fg-on-accent kullanılır.

**Desen kaynağı:** Pin 33 — mor, tamamen yuvarlatılmış yüzen kenar çubuğu

**Tüketiciden beklenen:** `components/bundle.css` yüklü olmalı; örnekteki HTML yapısı ve sınıf adları aynen korunur. İkonlar Lucide (1.75 px), satır içi SVG.
