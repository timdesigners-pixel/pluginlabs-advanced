# Seçim Kutusu

Native <select> üzerine token tabanlı stil.

**Kimlik:** `PLC-019` · **Kategori:** Form · **Katman:** temel

**Ne zaman:** 5+ seçenekli tekli seçim; 2–4 seçenek için Segment veya Radyo.

**Sınıflar:** `pl-select`

**Kapsayıcı:** `<div data-pl data-pl-theme="dark" lang="tr">`

**Erişilebilirlik:** Native select klavye ve ekran okuyucu uyumludur; özel dropdown yazma.

**Tüketiciden beklenen:** `components/bundle.css` yüklü olmalı; örnekteki HTML yapısı ve sınıf adları aynen korunur. İkonlar Lucide (1.75 px), satır içi SVG.
