# Renkli İkonlu İstatistik Kartı

Renk değişkenli (--c) ikon karosu, etiket, büyük mono değer ve değişim; 'is-hot' ile renkli zemin.

**Kimlik:** `PLA-053` · **Kategori:** Üretkenlik & İK · **Katman:** advanced

**Ne zaman:** Pano üst KPI satırı (4–5 kart).

**Durumlar:** varsayılan, vurgulu (is-hot)

**Sınıflar:** `pl-statcard is-hot pl-statcard__ic (--c) pl-statcard__lbl pl-statcard__val`

**Kapsayıcı:** `<div data-pl data-pl-theme="dark" lang="tr">`

**Erişilebilirlik:** Değişim yönü metinle ("+%12 artış").

**Desen kaynağı:** Pin 26 — 'Today appointments / Cancelled' renkli ikonlu kartlar

**Tüketiciden beklenen:** `components/bundle.css` yüklü olmalı; örnekteki HTML yapısı ve sınıf adları aynen korunur. İkonlar Lucide (1.75 px), satır içi SVG.
