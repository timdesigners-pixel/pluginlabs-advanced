# İK Kontrol Paneli

Soft yüzey (açık tema): hap üst gezinme, karşılama + büyük sayı üçlüsü, bölümlü ilerleme hapları; altta profil kartı, ince çubuk grafik, zaman takip kadranı, görev kartı ve günlük ajanda.

**Kimlik:** `PLA-097` · **Kategori:** Ekran Şablonları · **Katman:** advanced

**Ne zaman:** İK, ekip yönetimi, SaaS yönetim paneli; açık temalı tüketici panelleri.

**Sınıflar:** `pl-screen + pl-pillnav + pl-bigstats + pl-segpills + pl-photocard + pl-pinbars + pl-timer + pl-taskcard + pl-agenda`

**Kapsayıcı:** `<div data-pl data-pl-theme="light" data-pl-surface="soft" lang="tr">`

**Erişilebilirlik:** Açık temada --pl-fg-3 bile ≥4.5:1; büyük ince rakamlar ≥24px olduğundan 3:1 yeterli.

**Desen kaynağı:** Pin 39 — açık, krem tonlu, büyük rakamlı İK panosu

**Tüketiciden beklenen:** `components/bundle.css` yüklü olmalı; örnekteki HTML yapısı ve sınıf adları aynen korunur. İkonlar Lucide (1.75 px), satır içi SVG.
