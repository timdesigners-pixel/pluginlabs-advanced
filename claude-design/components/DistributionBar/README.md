# Dağılım Çubuğu

Bir bütünün kategori paylarını gösteren segmentli çubuk + lejant.

**Kimlik:** `PLC-041` · **Kategori:** Veri · **Katman:** temel

**Ne zaman:** Disk kullanımı, bütçe dağılımı, eklenti başına bellek.

**Sınıflar:** `pl-distbar > span (style="flex:<pay>") pl-legend`

**Kapsayıcı:** `<div data-pl data-pl-theme="dark" lang="tr">`

**Erişilebilirlik:** Lejant metni değerleri içerir; renk tek taşıyıcı değildir.

**Tüketiciden beklenen:** `components/bundle.css` yüklü olmalı; örnekteki HTML yapısı ve sınıf adları aynen korunur. İkonlar Lucide (1.75 px), satır içi SVG.
