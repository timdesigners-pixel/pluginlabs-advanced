# Dinamik Ada Oynatıcı

Siyah kapsül; kapak, başlık, ekolayzer animasyonu, konum çubuğu ve üç büyük kontrol.

**Kimlik:** `PLA-020` · **Kategori:** Medya & Eğlence · **Katman:** advanced

**Ne zaman:** Masaüstü 'şimdi çalıyor' yüzen kontrolü, Flow Dock medya modülü.

**Durumlar:** kompakt, genişletilmiş, duraklatıldı (ekolayzer durur)

**Sınıflar:** `pl-island pl-island__top pl-island__art pl-island__eq pl-island__ctl`

**Kapsayıcı:** `<div data-pl data-pl-theme="dark" lang="tr">`

**Erişilebilirlik:** Ekolayzer aria-hidden; prefers-reduced-motion'da animasyon durur.

**Desen kaynağı:** Pin 37 — genişletilmiş müzik oynatıcı adası

**Tüketiciden beklenen:** `components/bundle.css` yüklü olmalı; örnekteki HTML yapısı ve sınıf adları aynen korunur. İkonlar Lucide (1.75 px), satır içi SVG.
