# Canlı Skor Merkezi

Neon yüzey: sol ray, kahraman yayın kartı, öne çıkan neon kart ve maç satırları; sağda canlı skor ve oran paneli.

**Kimlik:** `PLA-093` · **Kategori:** Ekran Şablonları · **Katman:** advanced

**Ne zaman:** Canlı veri, turnuva, yarışma veya gerçek zamanlı karşılaştırma panoları.

**Sınıflar:** `pl-screen + pl-rail + pl-cinehero + pl-neoncard + pl-matchrow + pl-score + pl-ticker`

**Kapsayıcı:** `<div data-pl data-pl-theme="dark" data-pl-surface="neon" lang="tr">`

**Erişilebilirlik:** Skor değişimi aria-live="polite".

**Desen kaynağı:** Pin 4 — neon yeşil turnuva canlı yayın panosu

**Tüketiciden beklenen:** `components/bundle.css` yüklü olmalı; örnekteki HTML yapısı ve sınıf adları aynen korunur. İkonlar Lucide (1.75 px), satır içi SVG.
