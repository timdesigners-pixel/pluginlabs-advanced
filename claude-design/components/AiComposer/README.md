**Kimlik:** `PLC-061` · **Kategori:** Ürün Kalıpları · **Katman:** temel

**Ne zaman:** MyMind sohbeti, yan panel asistanları.

**Sınıflar:** `pl-composer pl-composer__bar pl-composer__send`

**Kapsayıcı:** `<div data-pl data-pl-theme="dark" data-pl-product="mymind" lang="tr">`
