# Klinik Paneli

Soft yüzey: ikon rayı, koyu karşılama bandı, renkli istatistik kartları, alan grafiği ve sağda randevu zaman çizelgesi.

**Kimlik:** `PLA-100` · **Kategori:** Ekran Şablonları · **Katman:** advanced

**Ne zaman:** Klinik, salon, danışmanlık randevu yönetimi; hizmet işletmesi panoları.

**Sınıflar:** `pl-screen + pl-rail + pl-greet + pl-statcard + pl-areachart + pl-apptl`

**Kapsayıcı:** `<div data-pl data-pl-theme="light" data-pl-surface="soft" lang="tr">`

**Erişilebilirlik:** Grafik için tablo alternatifi; randevular <ol>.

**Desen kaynağı:** Pin 26 — açık temalı klinik / randevu panosu

**Tüketiciden beklenen:** `components/bundle.css` yüklü olmalı; örnekteki HTML yapısı ve sınıf adları aynen korunur. İkonlar Lucide (1.75 px), satır içi SVG.
