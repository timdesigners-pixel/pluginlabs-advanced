# Etiket / Chip

Filtre, kategori ve kullanıcı etiketleri; kaldırılabilir.

**Kimlik:** `PLC-008` · **Kategori:** Temel · **Katman:** temel

**Ne zaman:** Çoklu seçim filtreleri, not etiketleri, arama kapsamları.

**Durumlar:** varsayılan, seçili, kaldırılabilir

**Sınıflar:** `pl-tag pl-tag.is-selected > button`

**Kapsayıcı:** `<div data-pl data-pl-theme="dark" lang="tr">`

**Erişilebilirlik:** Kaldır butonu aria-label="<etiket> etiketini kaldır".

**Tüketiciden beklenen:** `components/bundle.css` yüklü olmalı; örnekteki HTML yapısı ve sınıf adları aynen korunur. İkonlar Lucide (1.75 px), satır içi SVG.
