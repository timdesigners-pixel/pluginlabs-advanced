# Kategori Etiketli Liste

Renkli kategori pilli, sağa hizalı tutarlı liste (Astra serisiyle uyumlu).

**Kimlik:** `PLC-079` · **Kategori:** Ürün Kalıpları · **Katman:** temel

**Ne zaman:** Harcama/alışveriş listeleri, eklenti kaynak tüketimi.

**Sınıflar:** `pl-listrow + pl-badge--* + pl-num`

**Kapsayıcı:** `<div data-pl data-pl-theme="dark" lang="tr">`

**Erişilebilirlik:** Tutarlar sağa hizalı ve tabular.

**Tüketiciden beklenen:** `components/bundle.css` yüklü olmalı; örnekteki HTML yapısı ve sınıf adları aynen korunur. İkonlar Lucide (1.75 px), satır içi SVG.
