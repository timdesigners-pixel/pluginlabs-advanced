# Rozet

Kısa meta bilgi: sürüm, durum, sayı, Pro.

**Kimlik:** `PLC-006` · **Kategori:** Temel · **Katman:** temel

**Ne zaman:** Bir öğenin niteliğini 1–2 kelimeyle işaretlemek için.

**Durumlar:** nötr, accent, success, warning, danger, info, pro, count

**Sınıflar:** `pl-badge pl-badge--accent|success|warning|danger|info|pro|count`

**Kapsayıcı:** `<div data-pl data-pl-theme="dark" lang="tr">`

**Erişilebilirlik:** Sayaç rozetlerinde görünmez metin: <span class="sr-only">3 bildirim</span>.

**Tüketiciden beklenen:** `components/bundle.css` yüklü olmalı; örnekteki HTML yapısı ve sınıf adları aynen korunur. İkonlar Lucide (1.75 px), satır içi SVG.
