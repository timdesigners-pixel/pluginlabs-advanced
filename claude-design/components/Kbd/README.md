# Klavye Kısayolu

Kısayol tuşlarının gösterimi.

**Kimlik:** `PLC-011` · **Kategori:** Temel · **Katman:** temel

**Ne zaman:** Menülerde, tooltiplerde, komut paletinde, arama kutusunda.

**Sınıflar:** `pl-kbd`

**Kapsayıcı:** `<div data-pl data-pl-theme="dark" lang="tr">`

**Erişilebilirlik:** <kbd> elementi kullanılabilir; Windows'ta Ctrl, macOS'ta ⌘ gösterilir.

**Tüketiciden beklenen:** `components/bundle.css` yüklü olmalı; örnekteki HTML yapısı ve sınıf adları aynen korunur. İkonlar Lucide (1.75 px), satır içi SVG.
