# İkon Buton

Araç çubukları ve satır eylemleri için kare buton.

**Kimlik:** `PLC-002` · **Kategori:** Temel · **Katman:** temel

**Ne zaman:** Eylemin anlamı ikonla evrensel olarak anlaşılıyorsa (ayarlar, kapat, daha fazla).

**Durumlar:** varsayılan, hover, aktif (is-active), outline

**Sınıflar:** `pl-iconbtn pl-iconbtn--outline pl-iconbtn--sm is-active`

**Kapsayıcı:** `<div data-pl data-pl-theme="dark" lang="tr">`

**Erişilebilirlik:** aria-label ve title zorunlu; toggle ise aria-pressed.

**Tüketiciden beklenen:** `components/bundle.css` yüklü olmalı; örnekteki HTML yapısı ve sınıf adları aynen korunur. İkonlar Lucide (1.75 px), satır içi SVG.
