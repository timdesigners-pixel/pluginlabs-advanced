# Ürün / Fiyat Kartı

Kaydedilen ürünün görseli, fiyatı, değişimi ve mağazası.

**Kimlik:** `PLC-059` · **Kategori:** Ürün Kalıpları · **Katman:** temel

**Ne zaman:** MyWishlist kataloğu, Ultimate Scrapper sonuçları. Izgarada eşit boyutlu.

**Sınıflar:** `pl-product pl-product__img pl-product__body pl-price pl-price__now pl-price__old`

**Kapsayıcı:** `<div data-pl data-pl-theme="dark" data-pl-product="wishlist" lang="tr">`

**Erişilebilirlik:** Görselde alt; fiyat değişimi metinle ("%14 düştü").

**Tüketiciden beklenen:** `components/bundle.css` yüklü olmalı; örnekteki HTML yapısı ve sınıf adları aynen korunur. İkonlar Lucide (1.75 px), satır içi SVG.
