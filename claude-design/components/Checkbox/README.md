# Onay Kutusu

Bağımsız çoklu seçim; belirsiz (indeterminate) durumu destekler.

**Kimlik:** `PLC-020` · **Kategori:** Form · **Katman:** temel

**Ne zaman:** Listelerde toplu seçim, izin onayı, birden fazla seçenek.

**Durumlar:** boş, seçili, belirsiz, devre dışı

**Sınıflar:** `pl-check > input[type=checkbox]`

**Kapsayıcı:** `<div data-pl data-pl-theme="dark" lang="tr">`

**Erişilebilirlik:** Etiket input'u saran <label> içinde; belirsizlik JS ile el.indeterminate=true.

**Tüketiciden beklenen:** `components/bundle.css` yüklü olmalı; örnekteki HTML yapısı ve sınıf adları aynen korunur. İkonlar Lucide (1.75 px), satır içi SVG.
