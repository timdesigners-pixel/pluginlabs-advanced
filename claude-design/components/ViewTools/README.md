# Görüntüleyici Araç Kümesi

Harita / 3B sahne / plan üzerinde yüzen dikey veya yatay araç kümesi. Cam zemin, aktif mod aksan dolgulu.

**Kimlik:** `PLA-008` · **Kategori:** Kabuk & Pencere · **Katman:** advanced

**Ne zaman:** Tuval, harita, kat planı, 3B model görüntüleyicileri.

**Durumlar:** varsayılan, hover, aktif mod, yatay

**Sınıflar:** `pl-viewtools pl-viewtools--h button.is-active hr`

**Kapsayıcı:** `<div data-pl data-pl-theme="dark" lang="tr">`

**Erişilebilirlik:** role="toolbar" + aria-orientation; mod düğmeleri aria-pressed.

**Desen kaynağı:** Pinler 0, 1, 15 — 2D/3D geçişi, yakınlaştırma, döndürme düğmeleri

**Tüketiciden beklenen:** `components/bundle.css` yüklü olmalı; örnekteki HTML yapısı ve sınıf adları aynen korunur. İkonlar Lucide (1.75 px), satır içi SVG.
