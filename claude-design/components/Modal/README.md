# Modal Diyalog

Odaklı karar veya form için üst katman.

**Kimlik:** `PLC-050` · **Kategori:** Katman · **Katman:** temel

**Ne zaman:** Kullanıcıyı durdurması gereken kısa görevler; uzun içerik için Çekmece.

**Sınıflar:** `dialog.pl-modal pl-modal__head pl-modal__icon pl-modal__body pl-modal__foot`

**Kapsayıcı:** `<div data-pl data-pl-theme="dark" lang="tr">`

**Erişilebilirlik:** Native <dialog>.showModal(); odak tuzağı, Esc kapatır, odak tetikleyiciye döner.

**Tüketiciden beklenen:** `components/bundle.css` yüklü olmalı; örnekteki HTML yapısı ve sınıf adları aynen korunur. İkonlar Lucide (1.75 px), satır içi SVG.
