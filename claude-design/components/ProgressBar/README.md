# İlerleme Çubuğu

Belirli ve belirsiz ilerleme.

**Kimlik:** `PLC-038` · **Kategori:** Veri · **Katman:** temel

**Ne zaman:** İndirme, kurulum, kazıma görevi, kota kullanımı.

**Sınıflar:** `pl-progress > span (style="--pl-val:64%") pl-progress--indeterminate pl-progress--sm`

**Kapsayıcı:** `<div data-pl data-pl-theme="dark" lang="tr">`

**Erişilebilirlik:** role="progressbar" + aria-valuenow/min/max; belirsizde valuenow yok.

**Tüketiciden beklenen:** `components/bundle.css` yüklü olmalı; örnekteki HTML yapısı ve sınıf adları aynen korunur. İkonlar Lucide (1.75 px), satır içi SVG.
