# Kaydırıcı

Sürekli değer seçimi; dolgu --pl-val ile.

**Kimlik:** `PLC-023` · **Kategori:** Form · **Katman:** temel

**Ne zaman:** Ses, opaklık, AI yaratıcılık (temperature), önbellek boyutu.

**Sınıflar:** `pl-slider (style="--pl-val:62%")`

**Kapsayıcı:** `<div data-pl data-pl-theme="dark" lang="tr">`

**Erişilebilirlik:** Native range; aria-valuetext ile birimli değer ("%62").

**Tüketiciden beklenen:** `components/bundle.css` yüklü olmalı; örnekteki HTML yapısı ve sınıf adları aynen korunur. İkonlar Lucide (1.75 px), satır içi SVG.
