# Zaman Takip Kadranı

Çentikli (tick) dairesel kadran, ortada büyük süre; altında oynat/duraklat ve zamanlayıcı düğmeleri.

**Kimlik:** `PLA-047` · **Kategori:** Üretkenlik & İK · **Katman:** advanced

**Ne zaman:** Odak zamanlayıcı, çalışma süresi takibi, pomodoro.

**Durumlar:** çalışıyor, duraklatıldı, hedefe ulaşıldı

**Sınıflar:** `pl-timer pl-timer__wrap pl-timer__dial is-partial (--v) pl-timer__val pl-timer__ctl`

**Kapsayıcı:** `<div data-pl data-pl-theme="dark" lang="tr">`

**Erişilebilirlik:** Süre <time> içinde; her dakika değil yalnız durum değişince aria-live.

**Desen kaynağı:** Pin 39 — '02:35 Work Time' çentikli dairesel sayaç

**Tüketiciden beklenen:** `components/bundle.css` yüklü olmalı; örnekteki HTML yapısı ve sınıf adları aynen korunur. İkonlar Lucide (1.75 px), satır içi SVG.
